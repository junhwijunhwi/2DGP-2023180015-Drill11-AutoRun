## 검증 중 발견·수정한 사항

- AutoRun의 5초 타임아웃은 `tick(frame_time)`으로 전달되므로 Idle 복귀 콜백에서 선택적인 `frame_time` 인자를 받도록 수정했다. 키 입력으로 복귀하는 기존 경로도 유지했다.
- 이벤트에 반복 여부 필드가 없어도 A를 누른 상태를 추적한다. 계속 누르고 있는 A로 5초 종료 직후 AutoRun이 다시 시작되지 않으며 키를 떼었다가 새로 눌러야 한다.
- SDL dummy 드라이버는 가속 렌더러를 지원하지 않는다. 검증 도구에서 소프트웨어 렌더러를 명시해 실제 이미지와 그리기 API를 검증했다. 게임 실행 코드를 대체한 것이 아니다.
- 종료 조건을 먼저 처리하면서 마지막 프레임의 이동이 생략되던 부분을 수정했다. 타임아웃 전 남은 시간만 이동한 뒤 Idle로 전환하므로 20초 늦게 갱신되더라도 AutoRun은 5초만 이동한다.
- pico2d가 창 포커스 이벤트를 반환하지 않는 것을 확인했다. 게임 루프에서 실제 키보드 포커스를 확인해 입력 해제를 수행한다.

## 직접 실행 시 확인 순서

1. `python main.py`로 실행하고 Idle에서 A를 누른 뒤 키를 뗀다.
2. 소년이 커지고 빨라져 양 끝에서 반사되는지 확인한다.
3. 5초 후 작아지며 Idle이 되는지 확인한다.
4. 다시 A를 누르고 AutoRun 도중 방향키로 취소한다.
5. 방향키를 떼어 Idle로 돌아오고, Idle에서 5초 후 Sleep이 되는지 확인한다.
6. 방향키를 누르며 다른 창으로 전환하고 키를 뗀다. 게임으로 돌아왔을 때 소년이 계속 달리지 않는지 확인한다.
